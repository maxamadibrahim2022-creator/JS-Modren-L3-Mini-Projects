Inventory Catalog

ES6 Features Applied:

  • Destructuring: Used in rendering components to extract { name, price, tags, ...rest } directly from product objects, and array destructuring for tags [firstTag, ...otherTags].
  • Spread Operator (`...`): Used to clone the products array, append new items without mutating state, merge default tags, and apply discounts to object clones.
  • Rest Parameters (`...rest`): Used to gather all dynamic metadata properties (SKU, Supplier) into a single extra details object.
